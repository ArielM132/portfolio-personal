02 · Sobre mí

Código con criterio visual.

Me interesa el punto donde una interfaz deja de ser solamente correcta y empieza a sentirse clara, propia y agradable de usar.

Comencé construyendo páginas con HTML y CSS. A medida que avancé, incorporé JavaScript para trabajar con datos, manipular el DOM, validar formularios y crear experiencias de compra completas en el navegador.

Hoy desarrollo sitios frontend desde la estrategia visual hasta la publicación. Trabajo de forma organizada con Git y GitHub, leo documentación técnica en inglés y sigo profundizando mis conocimientos para abordar proyectos cada vez más completos.

  1. 01

    Entender antes de diseñar

    Primero identifico el objetivo, el usuario y la información que debe ganar protagonismo.

  2. 02

    Diseñar con intención

    Jerarquía, tipografía, color y movimiento tienen que ayudar a comunicar, no decorar por decorar.

  3. 03

    Construir para todos

    Responsive, semántica, contraste, foco visible y buen rendimiento forman parte del producto.

03 · Habilidades

Lo que puedo aportar hoy.

Una base frontend sólida, una mirada sensible al diseño y el criterio para mantener cada proyecto simple, usable y fácil de continuar.

Frontend

Estructuras semánticas, estilos escalables y comportamiento dinámico sin dependencias innecesarias.

Interactividad

Interfaces que responden a los datos y a las decisiones del usuario.

Calidad y entrega
