# Portfolio personal — Carlos Ariel Morales

Rediseño completo del portfolio personal con enfoque profesional, responsive y accesible. Está construido únicamente con HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.

## Contenido del proyecto

- `index.html`: estructura, contenido, SEO y enlaces.
- `styles.css`: sistema visual completo, responsive y temas claro/oscuro.
- `script.js`: selector de tema, menú móvil, animaciones, navegación activa y copia del correo.
- `favicon.svg`: ícono del sitio.
- `assets/`: retrato optimizado y capturas de proyectos.

## Cómo verlo en VS Code

1. Abrí esta carpeta completa en VS Code.
2. Instalá la extensión **Live Server** si todavía no la tenés.
3. Hacé clic derecho sobre `index.html`.
4. Elegí **Open with Live Server**.

También podés abrir `index.html` directamente en el navegador. Live Server es más cómodo porque actualiza la página al guardar cambios.
